## 1. 优化思路

| 主题 | 思路 | 落地 |
| --- | --- | --- |
| 战斗排版 | 像素字号撑破 grid；overlay 占行导致叠字 | 战斗区显式 `grid-area`；时间轴/组合台按内容高；窄屏底栏保持三列 |
| 敌方时间轴 | 只显示下一次行动不够读 | **展望 15s**，投影每人窗口内全部行动（约 3 次） |
| 我方时间轴 | 咏唱外还有自动线 | 装备间隔伤 / 延迟命中（交流电等）/ 召唤物攻击分轨 |
| 召唤流 | 卡表有元素人等，需可打可看 | `spawnAlly` + 自动攻击 tick；共鸣/奉献/殉道等效果接通 |
| 组合交互 | 叠牌即组合，先看清产物 | 拖牌叠合 → 组合台显示 **材料 → 产物 + 效果**；点「合成」才入手 |
| 牌堆透明 | STS 式可查阅 | 点击牌堆 / 弃牌打开列表（名称·类型·咏唱·描述） |

---

## 2. 流程（实现顺序）

```text
战斗布局修复（grid 占位 / 组合台结构 / 窄屏手牌）
  → timelineSnapshot(15)：敌方多行动投影
  → 我方装备 / 延迟 / 召唤物轨
  → 召唤物生成与自动攻击 + 字词效果
  → 叠牌入组合台 + 公式/效果预览（取消自动合成）
  → 牌堆 / 弃牌查阅面板
  → 本归档 + push GitHub
```

---

## 3. 时间线（本档）

| 节点 | 说明 |
| --- | --- |
| 布局修复 | `#target-layer` / overlay 不再挤占时间轴行；组合台标题与槽位分层 |
| 15s 敌轴 | 每单位 `nextActionAt + 5s…` 含窗口右端 |
| 15s 我轴 | 咏唱 / 装备 / 延迟 / 召唤分轨；刻度按 15 格 |
| 召唤 | `combat.spawnAlly`；元素人等 WORD_EFFECTS |
| 叠牌预览 | `paintCraftPreview`：`A + B → 产物` + 效果文案 |
| 牌堆查看 | `#pile-viewer`；牌顶在上；Esc / 点遮罩关闭 |
