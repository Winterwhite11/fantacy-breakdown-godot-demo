## 卡牌核心机制思路

卡牌体系分为由每个基本「字」作为基础铭文，以及通过复数个基本「字」组合成的复杂「字词」来构成。例如玩家抽到「水」与「火」两张基础卡牌后可以自行选择将其组合成「气」字，而「气」也可以通过事件，击杀怪物，商店获得（类似杀戮尖塔）。

### 核心卡机制

每个玩家会获得一张自己独有的基础铭文，该铭文只有这局游戏存在？同时每个玩家也拥有铭文组合上限，具体数值取决于玩家的铭文耐性，如豪杰的铭文耐性为6，即操作豪杰时一个复杂「字」最多只能由6个基本字堆叠，同时正常情况下，每张基本卡通常只花费一秒发动，同时随着基本卡的字句堆叠咏唱时间会同步增长，因此选择组合时也需要避免不必要的组合：如气只需要1秒，但如果气是通过水与火组合形成则需要2秒，咏唱时间以堆叠字词数作为参考，不考虑其余因素，此外每次咏唱存在前后摇（前摇0.5s 后摇1.5s）。

因此游戏卡牌核心机制本质是对杀戮尖塔的模仿，但是加入了类似炼金与搜打撤的改变与玩法，目前暂时围绕这一计划开展，但后续可能会做出调整与创新更改。

### 数值量化

| 咏唱时间 | 对应伤害 |
| ---: | ---: |
| 1秒 | 5伤害 |
| 2秒 | 12点伤害 |
| 3秒 | 21点伤害 |
| 4秒 | 32点伤害 |

护甲只会存在5秒。

常规元素4伤，危害元素5伤，无害元素3伤。

元素可以单独打出，但更多情况下组合才能发挥最大作用，元素是卡牌体系核心基本资源。

### 元素人机制

玩家释放对应元素攻击后相同元素的元素人会同步进行一次无视cd的攻击。

## 词条解释

| 词条 | 解释 |
| --- | --- |
| 燃烧 | 每回合结束受到燃烧层数1半的伤害，随后燃烧层数减半 |
| 中毒 | 每回合结束受到中毒层数的伤害，随后中毒层数加1 |
| 冻结 | 获得冻结值，当冻结值高于10层时获得虚弱，当冻结值高于20层时获得易伤，当冻结值高于生命上限时死亡 |
| 辉煌 | 每持有一层辉煌，战斗结束时获得代币增加10 |
| 激昂 | 持续10秒，每层单独计算，在后续10秒内造成的所有伤害增加激昂层数 |
| 免疫 | 5秒内每次只会受到一点伤害 |
| 坚韧 | 护甲持续时间延长到20秒 |
| 穿透 | 攻击护甲时护甲削减层数翻倍 |
| 环境 | 该词条只能存在一个，后续赋予会覆盖 |
| 隐匿 | 低于隐匿层数的伤害不会生效，每隔5秒隐匿层数减半 |
