## 0. 保留的原始设计意图（不得改写）

以下条目逐字来自用户 `card table.docx` 原文，是本次体系的**设计前提**，任何数值调整都不得违背：

### 0.1 核心机制（原文段 003 / 004）

- 卡牌体系 = 基本「字」（铭文）+ 复数「字」组合成的复杂「字词」。
- 每个玩家拥有**铭文耐性**，决定一个复杂「字」最多由几个基本字堆叠（如**豪杰耐性为 6**）。
- 每张基本卡通常花费 **1 秒**发动；**咏唱时间以堆叠字词数作为参考**。
- 组合同样需要避免不必要的组合：**气本身 1 秒，但水+火合成的气需要 2 秒**。
- 每次咏唱存在前后摇：**前摇 0.5s / 后摇 1.5s**。
- 本质是对杀戮尖塔的模仿，但**加入炼金与搜打撤**。

### 0.2 数值量化（原文段 004，**现行真源，用户 2026-10-12 拍板**）

| 咏唱 | 伤害 |
| ---: | ---: |
| 1 秒 | 5 |
| 2 秒 | 12 |
| 3 秒 | 21 |
| 4 秒 | 32 |

**护甲只会存在 5 秒。**

### 0.3 卡牌来源（原文段 001 + 用户 2026-10-12 确认）

- 基础字可通过**事件、击杀怪物、商店**获得（类似杀戮尖塔）。
- 卡牌可**从地图成功撤出带出**。
- 卡牌可在**自由市场用代币购买**（"战备"）。

### 0.4 合成分层（用户 2026-10-12 确认）

| 场所 | 行为 | 材料 | 产物 |
| --- | --- | --- | --- |
| 战斗中组合台 | 即时合成 | **临时**（产物进弃牌堆时分解回材料） | 本场有效 |
| 地图 / 牌库界面 | 永久合成 | **消耗掉** | 写入永久牌组 |

## 1. 本体系解决的核心问题

**旧 demo 的经济断点（实测）：**

| 来源 | 数值 |
| --- | ---: |
| 普通战代币奖励 | 6 ~ 30 |
| 商店买一张随机卡 | 12 |
| 收集品出售价值（白） | 40 ~ 160 |
| 收集品出售价值（紫） | 1400 ~ 2800 |
| 收集品出售价值（唯一） | 16000 ~ 38000 |

**卡牌价格锚点（12）比一件白收集品还低。** 玩家最优解是"捡垃圾卖市场"，搜打撤的取舍不成立。

**本体系要建立的就是缺失的那一层：卡牌定价。**

## 2. 核心公式

### 2.1 窗口价值 WV（Window Value）

所有数值折算到唯一的尺度：**一个 5 秒行动窗口**。
依据：敌人每 5s 行动一次、状态每 5s 结算一次、玩家每 5s 约出 1 张牌。

```
WV = 伤害×1.0 + 护甲×0.7 + 治疗×1.0 + 燃烧×0.5 + 中毒×0.8
   + 冻结×0.4 + 激昂×2.5 + 辉煌×3.0 + 其他状态×1.0
```

### 2.2 卡牌价格 P（自动定价公式）

**基础牌：**

```
P_base = round( BASE_COST + PRICE_PER_WV × (WV / 5) )
```

**合成牌（含合成链深度加权）：**

```
材料价值 MV = MATERIAL_WEIGHT × Σ P(材料)
加工增值     = MV × ASSEMBLY_RATE × 材料数        // 链越深，增值越高
爆发溢价     = BURST_RATE × max(0, WV − 基准WV(该咏唱档))
P_product    = round( MV + 加工增值 + 爆发溢价 )
```

**设计意图（必须满足的约束）：**

1. **链越深越贵**：3 材料牌价格 > 其材料之和。
2. **性价比必须单调递减**：`基础牌 WV/P > 合成牌 WV/P`，且越深的产品性价比越低。
   → 这是"跑刀 vs 猛攻"能成立的结构前提：**便宜的牌效率高，贵的牌绝对强度高**。
3. **不产生唯一解**：不存在一张牌在其档位全面优于所有同价牌。

### 2.3 系数表（可在 `economy.js` 中调整）

| 系数 | 值 | 说明 |
| --- | ---: | --- |
| `BASE_COST` | 2.0 | 基础牌基准价 |
| `PRICE_PER_WV` | 0.9 | 每 5 点 WV 的价格 |
| `MATERIAL_WEIGHT` | 0.8 | 材料价值折损（合成不保留全部价值） |
| `ASSEMBLY_RATE` | 0.22 | 每材料数的加工增值率 |
| `BURST_RATE` | 0.18 | 超出档位基准的爆发溢价率 |

## 5. 三条获取通道与风险模型

| 通道 | 代币 | 卡牌归宿 | 败北风险 |
| --- | --- | --- | --- |
| 战斗掉落 / 事件 | — | `runMeta.staging` | **全损** |
| 地图商店购买 | 本局代币 | 本局牌组 | **全损** |
| 自由市场购买 | **vault 代币** | vault 牌组 | **全损**（若带入） |
| **成功撤离** | 本局代币 → vault | staging → vault | — |

### 期望值模型（跑刀 / 猛攻的数学形式）

设战备总成本 `C`、存活率 `p`、撤离收益 `V`：

```
EV = p × V − (1 − p) × C
盈亏平衡存活率  p* = 1 − V / (C + V)
```

**两条路线成立的唯一条件：高价值内容必须被威胁门槛保护。**
若猛攻能拿的东西跑刀也能拿，跑刀严格占优，猛攻体系死亡。

| 路线 | 成本 C | 威胁门槛 | 收益 V | 目标存活率 p |
| --- | --- | --- | --- | ---: |
| 跑刀 | 低 | 一~二档 | 低 | ≥ 80% |
| 常规 | 中 | 三档 | 中 | 60 ~ 75% |
| 猛攻 | 高 | 四~五档 | 高 | 40 ~ 60% |

## 6. 威胁门槛表（依据实测敌方 DPS）

玩家生命 60，要求"可撑时长"落在目标区间。实测基准：

| 敌方 DPS | 玩家可撑 | 评定 |
| ---: | ---: | --- |
| < 0.6 | > 100s | 几乎无威胁（不可接受） |
| 0.6 ~ 1.2 | 50 ~ 100s | 偏软 |
| 1.2 ~ 2.2 | 27 ~ 50s | **合理** |
| 2.2 ~ 3.0 | 20 ~ 27s | 偏难（精英） |
| > 3.0 | < 20s | 危险（四~五档） |

**目标档位区间：**

| 档位 | 目标敌方 DPS | 目标总HP | 玩家最低需求 DPS |
| --- | ---: | ---: | ---: |
| 一档 | 0.8 ~ 1.2 | 16 ~ 30 | ≤ 0.6 |
| 二档 | 1.4 ~ 2.0 | 60 ~ 80 | 1.5 ~ 2.0 |
| 三档 | 1.6 ~ 2.2 | 60 ~ 80 | 1.6 ~ 2.2 |
| 四档（精英） | 2.2 ~ 3.0 | 120 ~ 160 | 4.0 ~ 5.0 |
| 五档 | ≥ 3.0 | ≥ 200 | ≥ 6.0 |
