# 使用说明（详细）

本文档对应 **GDD-CLIENT-001** 与当前 `godot-demo` **灰盒**实现。

> **2026-09-18：** Godot 灰盒已**暂停扩玩法**。现行可玩验证床为 [`html-demo/`](../html-demo/README.md)，卡效以卡表咏唱制为准。下文仅描述灰盒操作，勿当作现行规则源。

仓库：https://github.com/Winterwhite11/fantacy-breakdown-godot-demo

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| 引擎 | Godot **4.2 或更高**（4.x） |
| 系统 | Windows / macOS / Linux |
| 网络 | 仅克隆仓库时需要；离线可玩 |

不需要导出模板即可在编辑器内试玩。

## 2. 安装与启动

### 2.1 从 GitHub 克隆

```bash
git clone https://github.com/Winterwhite11/fantacy-breakdown-godot-demo.git
cd fantacy-breakdown-godot-demo
```

### 2.2 用编辑器打开

1. 打开 Godot 4 → **Import** 或 **Open**
2. 选择本仓库根目录的 `project.godot`
3. 等待导入结束后按 **F5**（或点击右上角 Play）
4. 应先短暂进入 `main`，再自动进入**地图**场景

若报错缺少 Autoload：确认 `project.godot` 中存在：

- `CardLibrary`
- `GameState`
- `SceneRouter`

## 3. 地图操作

| 操作 | 说明 |
| --- | --- |
| `W A S D` 或方向键 | **每次只移动一格** |
| 灰墙 | 不可进入 |
| 蓝「起」 | 出生点 |
| 红「战」 | 踩上触发战斗 |
| 已清战斗格 | 颜色变深，不再进战 |
| 右上角「合成台（永久）」 | 打开地图合成 UI |
| 顶部「全局牌库」 | 显示当前永久牌库摘要 |

战斗失败后会出现「重新开始」，将重置 HP、地图进度与牌库。

## 4. 地图永久合成

1. 点击 **合成台（永久）**
2. 在列表中点选 **两张不同** 的全局牌库卡（高亮为已选）
3. 状态行会显示配方预览（如 `水 + 压缩 → 水刃`）或「无匹配配方」
4. 有配方时点 **确认永久合成**
5. 效果：**两张材料从全局牌库删除，一张结果加入全局牌库**（2→1，跨战斗保留）
6. **关闭** 返回地图

可多次合成。下次进入战斗时，牌组来自更新后的全局牌库。

## 5. 战斗操作

| 操作 | 说明 |
| --- | --- |
| 点击手牌 | 费用足够则打出；不足则日志提示 |
| **结束回合** | 手牌进弃牌堆 → 敌方行动 → 你的下回合 |
| **合成台** | 进入局内合成模式 |
| 选 2 张手牌 → **确认合成** | 瞬时 2→1，结果带〔局〕标记 |
| **退出合成 / 取消选择** | 离开合成模式 |
| 胜/负后 **返回地图** | 丢弃本局牌堆；局内合成全部失效 |

### 5.1 界面分区（仿杀戮尖塔）

- 左下：抽牌堆张数
- 右下：弃牌堆张数
- 底中：手牌区
- 底右：费用、结束回合、合成台
- 右侧：道具区占位（本版不可用）
- 上方：敌方生命 / 意图
- 左侧：战斗日志

### 5.2 抽牌规则（与 STS 差异）

1. 回合开始：能量回满，尝试抽 5 张
2. 抽牌过程中若抽牌堆空了：**不会**立刻把弃牌堆洗回来
3. **下一回合开始时**，若抽牌堆不足以抽满，才把弃牌堆洗入抽牌堆，再抽牌

建议自测：连续打光抽牌堆后结束回合，观察日志与张数变化。

### 5.3 战斗瞬时合成 vs 地图永久合成

| | 地图 | 战斗 |
| --- | --- | --- |
| 材料 | 全局牌库 | **仅手牌** |
| 结果 | 永久 | 仅本局（〔局〕） |
| 战后 | 保留 | 失效（全局牌库未改，等同 1→2） |

## 6. 首测卡牌与配方

基础字：水 / 火 / 气 / 毒 / 砂  
处理：压缩 / 堆砌

| 材料 | 结果 | 费用 | 效果摘要 |
| --- | --- | ---: | --- |
| 火+气 | 蒸汽 | 2 | 5 伤 |
| 水+毒 | 酸 | 2 | 2 伤 + 清一半护甲 |
| 水+压缩 | 水刃 | 2 | 12 伤 |
| 砂+堆砌 | 土墙 | 2 | 12 甲 |
| 蒸汽+压缩 | 高压蒸汽 | 4 | 12 伤 |

数据文件：`data/cards.json`（改完后重开场景或重启游戏以重新加载）。

## 7. 验收清单

- [ ] F5 进入地图并可单格移动
- [ ] 踩红格进入战斗，可见抽/弃/手/费/道具占位
- [ ] 能打出卡并看到敌我数值变化
- [ ] 抽尽当回合不自动洗牌；下回合才可能补充
- [ ] 地图合成后全局牌库张数 -1，且再进战仍有字词
- [ ] 战斗合成出〔局〕卡；回地图后若未做过永久合成，全局牌库无该字词
- [ ] 战败可重开

## 8. 常见问题

**Q: 合成按钮点了没反应？**  
A: 战斗里需先进入合成模式并选满两张有配方的手牌，再点「确认合成」。

**Q: 为什么战斗合成的牌回地图没了？**  
A: 设计如此——局内瞬时合成不写全局牌库。要永久保留请用地图合成台。

**Q: 中文显示乱码？**  
A: 使用 Godot 4 默认字体一般可显示中文；若系统缺字体，可在项目里添加中文字体资源。

**Q: 与 `game_design` 仓库关系？**  
A: 构思与 GDD 在 `game_design`；本仓库是可执行客户端。代码设计合同见构思库中的 `GDD-CLIENT-001`。
