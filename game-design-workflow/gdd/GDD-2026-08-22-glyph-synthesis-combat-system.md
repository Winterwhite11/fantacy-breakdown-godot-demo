## 1. 产品与体验合同 `[必填]`

### 1.1 一句话概念

> 玩家以唯一本源字为身份，在回合中将基础铭文合成为字词并打出，在铭文耐性上限内权衡炼金深度、费用组件与处理协同，以击破对手或完成遭遇目标。

### 1.2 设计支柱

| 支柱 | 规则支撑 | 反面信号 |
| --- | --- | --- |
| 炼金成长 | 合成 + 掉落成品 | 只打基础字 |
| 可读费用 | 四层组件 + 标价表 | 现场拆层心算 |
| 身份差异 | 本源字解释 + 耐性 | 数值皮肤换名 |
| 可调平衡 | 改字词表与标价 | 改本源文本 |

### 1.3 与 GDD-001 关系

- **保留**：两人对战、血量、护盾、回合、攻防共享能量（4 点）可作为 `Hypothesis` 继承。
- **替换**：成语字段、核心卡 4 公开组合、羊/舟首测卡组 → **Parked**。
- **迁移**：原子结算、单行动位、防御响应窗口原则可沿用。

## 3. 规则总览 `[GDD-1]`

### 3.1 核心名词

| 术语 | 定义 |
| --- | --- |
| 基础字 | 元素/处理/手段层单字卡，可打出或作合成材料 |
| 字词 | 多字合成结果或掉落成品；带层数 |
| 层数 | 字词含基础字数量；≤ 铭文耐性 |
| 铭文耐性 | 单张字词层数上限（豪杰 6，王权 4 `Hypothesis`） |
| 本源字 | 核心铭文；跨局身份，解释规则不改配方 |
| 合成标价 | 打出字词时支付的费用（层数公式 + 组件修正） |
| 处理协同 | 201–208 规则；处理+元素增强 |

### 3.2 全局不变量

| ID | 规则 |
| --- | --- |
| INV-G01 | 每场战斗每名玩家恰好 1 张参战本源字 |
| INV-G02 | 字词层数不得超过当前角色铭文耐性 |
| INV-G03 | 合成不消耗行动位；打出字词消耗行动位与费用 |
| INV-G04 | 每回合免费合成 1 次；额外合成耗 1 费 `Hypothesis` |
| INV-G05 | 动态平衡只改字词表/标价/协同数值，不改本源机制文本 |
| INV-G06 | 金（008）不可单独打出，仅参与合成 |

### 3.3 费用模型

**组件直觉（设计层）：**

```text
标价 ≈ 元素层 + 处理方式层 + 使用手段层 + 修饰层
```

**层数基准（首测 `Hypothesis`，可下调）：**

| 层数 | 基准标价 |
| ---: | ---: |
| 1 | 4 |
| 2 | 8 |
| 3 | 13 |
| 4 | 20 |

特殊：冷气（202）可为 0–1 费，**每回合限 1 次**。

**与共享能量关系 `Hypothesis`：**

- 打出字词从当前 4 点攻防共享能量扣除标价。
- 压缩（101）弃牌获得的 2 费为**合成资源**，不突破 4 点战斗能量上限，或作为下一张标价减免——待 combat-lab 二选一验证。

### 3.4 合成流程

1. 选手牌中 ≥2 张基础字（或字词+字，若规则允许 `Unknown`）。
2. 系统显示可达字词、层数、标价、是否超耐性。
3. 确认合成 → 材料进入消耗区，字词入手牌。
4. 每回合第 1 次合成免费；之后每次 +1 费 `Hypothesis`。

## 4. 系统规格 `[GDD-1]`

### 4.1 SYS-G01：字素合成

| 项目 | 规格 |
| --- | --- |
| 目的 | 让玩家主动创造字词，缩短掉落依赖 |
| 输入 | 选择材料、确认合成 |
| 输出 | 字词卡入手牌；材料弃置 |
| 失败 | 超耐性 / 无配方 → 禁止并提示 |

### 4.2 SYS-G02：字词打出

| 项目 | 规格 |
| --- | --- |
| 目的 | 将炼金结果转为战斗效果 |
| 输入 | 选择字词、确认（攻击/防御窗口） |
| 消耗 | 合成标价 + 共享能量；占用行动位 |
| 结算 | 先基础字词效果，再触发处理协同（若适用） |

### 4.3 SYS-G03：处理协同（201–208）

当字词含「处理+元素」时，按 [card-table.md](../data/card-table.md) 201–208 表增强。首测至少实现：201 压缩范围、202 堆砌护甲、204 冷却减费。

### 4.4 SYS-G04：本源字解释器

同一张字词，不同本源字可改变：

- 伤害分流 / 溢伤转甲（稳系，豪杰向）
- 宣告后费用 -1（承诺系，王权向）
- 击杀额外掉落选项（收容系）

不改配方与层数。
