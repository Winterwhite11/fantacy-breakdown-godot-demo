## 一、机制底座：中毒是唯一「自加速」的体系

```js
// combat.js _settleStatusTick
if (poison > 0) { 伤害 = 当前层数; poison += 1; }   // 不衰减、无上限
```

对比四个体系的成长方式：

| 体系 | 结算行为 | 成长方式 |
| --- | --- | --- |
| 燃烧 | `ceil(层数/2)` 伤害，**层数减半** | 需要外部不断补燃 |
| 冻结 | **不结算伤害**，>10 虚弱 / >20 易伤 / 满层斩杀 | 不衰减，靠层数堆 |
| 激昂 | 每层 +1 伤害，持续 10s 后消失 | 短时爆发 |
| **中毒** | **伤害 = 层数，层数 +1** | **自己会长，且伤害递增** |

### 由此推出的两条设计铁律

1. **不设计成长牌。**
   中毒自己每结算就 +1，任何「以后中毒层数 +1」都是**冗余**（用户明确指出）。
   本体系 16 张新卡**没有任何成长类效果键**，`poison-test.mjs` A2 组守护此约束。

2. **自身中毒的倒计时是有限的。**
   层数会涨 → 自伤也会涨（4 层打 4，30 层打 30）。
   所以「毒自己」不是无风险资源，而是**一场赌局**：
   你有几回合把积累的毒变现，超时就被自己毒死。

## 二、体系定位：慢热

| 体系 | 缺陷 |
| --- | --- |
| 燃烧 | 没有护甲 |
| 激昂 | 没有过牌 |
| 冻结 | 除核心卡外没有直接伤害 |
| **中毒** | **慢热**——前期几无输出，且没有成长牌可加速 |

中毒的直接伤害普遍偏低（毒刃仅 5），价值主要压在「等待结算」上。
`poison-test.mjs` B10 组明确断言这个缺陷：打出当回合只造成本体伤害，毒要等结算才变现。

**补偿 = 两条风险回报闭环。**

## 三、两条风险回报闭环

```
A. 毒敌 → 引爆（输出闭环）
   308毒刃 / 309瘴气 / 310毒藤阵  累积敌人毒层
        ↓
   311毒爆(每层3伤) / 333瘟疫(翻倍+扩散) / 337万毒噬心(每层5伤+击杀回馈)
        ↑ 中毒原先完全没有爆发手段，这是本流派最缺的一环

B. 毒己 → 收益（资源闭环）
   326淬毒(自+3毒，换「攻击附带毒」) / 332血毒(自伤8换抽3)
        ↓
   327毒甲(每2层毒→1护甲) / 329嗜毒(每3层毒→1激昂) / 328蚀甲(半数毒→护甲)
        ↓
   330解毒(每层2伤) / 331化毒(每层1生命) / 335耐毒(中和10层)
        ↑ 必须主动收手 —— 否则被自己毒死（这是核心张力）
```

## 四、新增基础牌「菌」（013）

**为什么加**（用户的提示：「可以增加，但要符合逻辑」）：
中毒体系的词表里缺一味**毒性介质**。现实中毒素主要靠**微生物培养**产生
（肉毒杆菌、霉菌毒素），医药上的抗毒血清也来自培养。
现有材料（金/钢/砂/木/水/火/气/冰/电/灰）没有一个能表达「培养毒性」这件事，
导致 4 张卡的配方只能互相撞车。

`013：菌：培养的菌落，是毒素与发酵的来源 木+水`

被 4 张卡使用：`327毒甲`(菌膜成甲) · `330解毒`(培养中和剂) · `333瘟疫`(培养并扩散) · `335耐毒`(累积菌量耐受)。

### 配方去重结果

**15/16 唯一**。唯一重复：`毒+火+堆砌`（血毒 与 万毒噬心）。

> 这是**无法回避**的：既有卡表中 `238灰烬` 与 `246涅槃` 本身就是同一个 `木+火`，
> 是卡表既有的容忍做法。二者玩法角色完全不同（血毒=抽牌引擎，万毒噬心=斩杀终结），
> 且分属不同稀有度，故接受。

## 六、数值与经济

| 卡 | WV | 市场价 |
| --- | ---: | ---: |
| 337 万毒噬心 | 31 | 20,042 |
| 311 毒爆 | 18 | 12,626 |
| 310 毒藤阵 | 12.4 | 17,769 |
| 326 淬毒 | 3 | 2,758 |

### 一个必须记录的标定问题

`淬毒` 最初算出 **WV = −1.5**：我把 `poisonOnHit` 权重给成 3.0，
而 `selfPoison` 的惩罚 −1.5 直接把它压成负数。

但这是**错的**：`poisonOnHit` 对整局**每一次上毒**都生效（战斗越久越值钱），
是持续增益，不是一次性收益。修正为：
- `poisonOnHit: 6.0`（持续增益，应对标 kindle 这类全局杠杆）
- `selfPoison: -1.0` / `selfDamage: -0.8`（本体系里自身中毒**可以被变现**，
  惩罚不宜给重，否则「自作自受」这类核心牌会被系统性低估）

修正后 `淬毒` WV = 3，与它的实际强度相称。

> 定价公式对 WV ≤ 0 有兜底（`wvFactor = 1`，即给最低价），
> 所以负 WV 不会产出异常价格。目前唯一 WV 为负的卡是**既有的召唤流核心「奉献」**
> （`selfHpCost: -5`），这与它「自伤换增益」的定位一致。

## 七、待办与已知取舍

1. **自身中毒没有上限，也没法"扛住"**：目前只能靠中毒层数换护甲/回血来对冲。
   实战中「毒自己」的可持续层数约 10~20 层，再高就压不住。
   若日后想让毒自己成为主力玩法，需要一个「中毒伤害减免」类效果。
2. **引爆会把毒层清空**，之后必须重新累积。所以毒爆更适合作为斩杀手段，
   而非循环输出手段——这是有意的节奏设计（慢热 → 一波）。
3. **`瘟疫` 的扩散取「全场最高毒值」**，多目标战斗中偏强。
   若实测过强，可改为「按各自层数翻倍并不扩散到零层目标」。
4. **防御终端未设计**：冻结有 `325寒霜庇护`，中毒目前没有对应的高稀有度防御牌。
   若需要，可加一张「抗毒血清」（毒+菌+增幅+冷却），按自身毒层数持续回血。
5. **中毒没有跨体系出口**：现有唯一相关的是 `237焚化`（负面状态转燃烧）。
   若日后要补，可加「毒转冻结」（毒+冰）之类的转化轴。
