# 卡牌表（字素合成战斗 v0.1）

> **现行初版设计表已迁至：** [card-design-table-v0.2.md](card-design-table-v0.2.md)（用户 2026-09-09 原文结构化，内容未改）。  
> 下文为历史 v0.1 存档，仅供对照。

## 设计前提

- **两层牌**：基础「字」可打出，也可在手牌合成复杂「字词」。
- **核心卡**：每名玩家一张独有基础铭文（本源字）；建议跨局保留身份，本局获得辅铭/环境字。
- **铭文耐性**：单张字词最多堆叠的基础字数量（豪杰默认 6）。
- **费用组件**：`元素 1 + 处理方式 1 + 使用手段 1 + 修饰 1`（默认各 1 费层；成品字词打出时付合成标价）。
- **默认合成标价**（复杂字词）：`层数 × 层数 + 4`（2 层 = 8，3 层 = 13，4 层 = 20；首测可下调，见 GDD）。
- **玩法边界**：灵感来自杀戮尖塔式掉落/商店，但核心机制是字素合成，不是完整 STS 克隆。

## 元素层（001–008）

| ID | 字 | 单独打出 | 默认合成 | 备注 |
| --- | --- | --- | --- | --- |
| 001 | 水 | 水弹，4 伤 | 冷、酸、刃母体 | 可与冷却路线联动 |
| 002 | 火 | 火球，5 伤 | 蒸汽、热压母体 | 危险元素偏高伤 |
| 003 | 气 | 气体，3 伤 | 水+火 | 万能中间体 |
| 004 | 毒 | 4 层中毒 | 酸、毒气 | 状态系 |
| 005 | 砂 | 4 护甲 | 火+木（docx） | 土系母体 |
| 006 | 冰 | 冰刺，4 伤 | 水+冷却 | 控制向 |
| 007 | 木 | 木刺，2×2 伤 | 水+砂 | 成长/寄生线 |
| 008 | 金 | 5 伤 | — | **无单独效果**，仅参与默认合成 |

元素基准：常规元素 1 费 ≈ 4 效；危险元素（火）≈ 5 效；无害元素 ≈ 3 效。

## 处理 × 元素协同（201–208）

> 与任意元素字组合时，按「处理 X + 元素」增强该元素当次效果。

| ID | 规则 | 效果 |
| --- | --- | --- |
| 201 | 压缩+元素 | 压缩 X：该次获得范围 +1 格伤害 |
| 202 | 堆砌+元素 | 堆砌 X：获得护甲 +1 |
| 203 | 沸腾+元素 | 沸腾 X：伤害/护甲每跳 +3 |
| 204 | 冷却+元素 | 冷却 X：该字词费用 -1 |
| 205 | 冷却+沸腾+元素 | 触发元素沸腾强化（具体数值首测） |
| 206 | 缓冲+元素 | 缓冲 X：该元素伤害/护甲效果 ×150% |
| 207 | 回放+元素 | 回放 X：该次效果再结算 50% |
| 208 | 回放+元素（强化） | 回放 X：可连续释放 2 次 |

可成长字段示例：压缩水刃、压缩水枪、堆砌水墙等，依最后一层处理决定护甲或伤害取向。
