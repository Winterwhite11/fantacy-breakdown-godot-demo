# Fantacy Breakdown · HTML 试玩 Demo

浏览器即可测试：**主菜单 → 棋盘地图 → 战斗（1.pdf 布局 + 时间轴）**。

## 启动

在本目录或仓库根目录开本地服务（推荐，避免部分浏览器拦截音频）：

```bash
# 在 godot-demo 目录下
python -m http.server 8765
```

浏览器打开：

[http://127.0.0.1:8765/html-demo/](http://127.0.0.1:8765/html-demo/)

也可直接双击 `index.html`（音乐路径依赖相对 `../assets/`）。

## 操作

| 界面 | 操作 |
| --- | --- |
| 主菜单 | 「进入游戏」；战备/市场为预留灰显；「设置」调音量与战斗倍速 |
| 地图 | 点击**相邻格**移动；战斗/精英/事件/宝箱图标来自 `assets/ui/map-nodes` |
| 战斗 | **单击**选手牌，再点「咏唱打出」释放（再点同一张也可快捷打出）；**右键**/`C` 放入组合台 |
| 组合台 | 「合成」消耗材料，**产物进手牌**；配方源为本地 `card table.docx` |
| 时间 | **默认静止**；点「时间流动」或空格 **+0.5s**；**咏唱打出后自动流至后摇结束**，再静止 |
| 音乐 | 主菜单《拓宇者2》；战斗中《战斗》 |

## Demo 规则摘要

- 玩家 HP **60**；起始手牌 **5**；战斗时间每累计 **2s** 抽 1 张（手牌上限 10）
- 测试牌库：火/水/砂/木各 3；压缩、加热、冷却、堆砌、增幅各 1
- 咏唱：前摇 **0.5s** + 咏唱秒数 + 后摇 **1.5s**；护甲持续 **5s**
- 怪物：随机 ENC-01～10；每个单位行动回合 = **5s**
- 燃烧/中毒/流血/隐匿等 Debuff：**每 5s** 结算一次（与行动回合对齐）
- 占位美术：空白背景、蓝/红胶囊、长方形卡牌
## 文件
