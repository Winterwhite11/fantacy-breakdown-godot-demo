# Fantacy Breakdown · HTML 试玩 Demo

浏览器即可测试：**主菜单 → 整理战备 → 棋盘地图 → 战斗（咏唱时间轴）**。

> **权威规则：** 卡效与战斗节奏以 `card table.docx`（咏唱制）为准。本目录是现行可玩验证床；Godot 客户端为灰盒并**暂停扩玩法**。

## 启动

在本目录或仓库根目录开本地服务（推荐，避免部分浏览器拦截音频）：

```bash
# 在 godot-demo 目录下
python -m http.server 8765
```

浏览器打开：

[http://127.0.0.1:8765/html-demo/](http://127.0.0.1:8765/html-demo/)

也可直接双击 `index.html`（音乐路径依赖相对 `../assets/`）。

## 操作

| 界面 | 操作 |
| --- | --- |
| 主菜单 | 「进入游戏 / 继续游戏」读档；「新开一局」清档重开；「整理战备」；「设置」调音量 |
| 整理战备 | 装备：拖拽/双击穿戴；卡牌：炉石式仓库↔携带牌组（建议 ≥10，开战不足用标点卡填充） |
| 地图 | 相邻格移动；精英=Hard 池「冰与火」；**撤离点**在随机角落，抵达即可随时通关；进度写入 localStorage；败北清档 |
| 战斗 | **单击**选手牌，再点「咏唱打出」释放（再点同一张也可快捷打出）；**右键**/`C` 放入组合台 |
| 组合台 | 「合成」消耗材料，**产物进手牌**；耐性 **5**；配方源为本地 `card table.docx` |
| 时间 | **默认静止**；点时间轴旁「时间流动」或空格 **+0.5s**；**咏唱打出后自动流至后摇结束**，再静止 |
| 音乐 | 主菜单《拓宇者2》；战斗中《战斗》 |

## Demo 规则摘要

- 基础最大生命 **60**（装备可提升）；起始手牌 **5**；战斗时间每累计 **2s** 抽 1 张（手牌上限 10）
- 携带牌组建议 ≥**10**；不足时开战用无意义**标点卡**随机填充
- 咏唱：前摇 **0.5s** + 咏唱秒数 + 后摇 **1.5s**；护甲持续 **5s**（坚固可延长）
- 遭遇池：**普通战** ENC-01～09；**Hard / 精英** 仅「冰与火」（冰法师+火法师），固定掉落紫色收集品「寒霜结晶」「炽火余烬」+ 更高代币
- Debuff / 环境：**每 5s** 结算一次（与行动回合对齐）
- 通关：走到地图**随机四角**之一的「撤」格即可随时撤离成功（无解锁门槛）
- 存档：`localStorage` 键 `fb_html_demo_run_v1`（地图 / 战备 / 代币 / HP / 胜场）；通关或败北清除
- 地图事件：异星村落名著事件（明日方舟式 UI）；代币/道具已接入，道具暂无效果
- 战备：简易/普通背包（2/5 格）；收集品展厅+仓库；战后背包满可替换，无背包则诅咒入组
- 败北：本局锁定，须「新开一局」或清档后重开

## 文件

- `index.html` — 菜单 / 战备 / 地图 / 战斗 UI
- `js/card-data.js` — 由卡表生成的数据
- `js/cards.js` — 卡牌、合成、标点填充牌
- `js/loadout.js` — 战备（装备 / 牌组 / 仓库 / 收集品）
- `js/loot.js` — 战后奖励与收集品稀有度
- `js/save.js` — 本局 localStorage 存读
- `js/encounters.js` — 普通池 + Hard 池
- `js/combat.js` — 实时战斗与时间轴
- `js/map.js` / `js/app.js` — 地图、撤离与流程
